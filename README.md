## Executive Summary

This repository provides a complete enterprise deployment guide for building a knowledge-enhanced AI agent using Microsoft Foundry IQ, Azure AI Search, Azure Identity, and Azure AI Projects SDK.

---

## Project Overview

The objective is to create an enterprise knowledge assistant capable of retrieving information from connected knowledge sources and responding with accurate, grounded answers.

project_client = AIProjectClient(
    endpoint=endpoint,
    credential=DefaultAzureCredential(),
)
